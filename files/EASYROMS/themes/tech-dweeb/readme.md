TECHDWEEB EMULATION STATION THEME
- Custom TD Background artwork (Mom's basement!)
- 9 unique colour schemes to choose from
- System icons for all the popular systems
- Custom fonts and interface design
- Detailed gameslist view with pixel-riffic overlay
- Grid view with overlay
- Basic view without a bunch of malarky
- Font size options
- Aspect ratio correction for ultrawide displays
- That's all you get. More than you deserve, to be honest.

INSTALL
- Unzip
- Add the 'TechDweeb' folder to the 'themes' folder on your emulation station doodad
- Open 'User Interface' settings from the main menu
- Select 'TechDweeb' from the 'theme set' menu
- Customize colour and other options from the 'theme configuration' menu
